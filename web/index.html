local-model-launcher

一键启动本地 LLM 与 Stable Diffusion 文生图模型的图形界面应用。内嵌终端日志与模型网页界面，支持应用内下载模型与运行环境，模型目录可 OTA 在线更新。

为什么用启动器

把 llama.cpp / stable-diffusion.cpp 等命令行后端，封装成开箱即用的桌面应用

⚡

一键启动

卡片上点「▶ 启动」，服务就绪后右侧自动加载网页界面；「🖥 终端」标签可看实时日志。

⬇

应用内下载

未安装的模型点「⬇ 下载」，可选下载源（魔搭 / HF 镜像），支持断点续传；取消后再点会继续。

🔧

多后端支持

自动下载并解压 llama.cpp / stable-diffusion.cpp（CPU / Vulkan / CUDA / SYCL / HIP / OpenVINO）。

🔄

OTA 在线更新

启动时自动拉取 manifest.json，云端版本更大时自动覆盖内置目录——新增模型无需重装应用。

🎨

文生图

SDXL / SD3.5 / FLUX 已自动附加 —vae-on-cpu 防 8GB 核显 OOM，文本编码器与 VAE 随主模型补齐。

🔌

OpenAI 兼容 API

启动对话模型后暴露 http://127.0.0.1:8080/v1，可被其它 AI 软件直接调用（支持局域网 0.0.0.0）。
